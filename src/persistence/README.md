The persistence layer validates and serializes handoff state at storage boundaries. Persisted additions, including optional draft BLUF/definition-of-done metadata and a pending command-line model override, remain optional so older session entries decode. Drafting envelopes are a strict union of the ordinary required `Draft` shape and the leftovers-only `{ noLeftovers: true, rationale }` exit; the ordinary validator rejects that exit. It follows `domain <- app <- adapters <- index.ts` and does not construct concrete adapters.
